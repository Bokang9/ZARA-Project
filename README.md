## 3. Project Overview

The ZARA South Africa Website Redesign is a proposed website project aimed at creating a modern, responsive and user-friendly online experience for ZARA customers in South Africa.

ZARA is one of the world's foremost international fashion retailers and operates under the Inditex Group. Founded in Spain in 1975 by Amancio Ortega and Rosalia Mera, ZARA has expanded to more than 90 countries worldwide, including South Africa. ZARA offers customers a wide selection of clothing, footwear, accessories and beauty products for women, men and children.

The redesigned website aims to maintain ZARA's clean, modern and minimalist brand identity while improving the way users find products, access customer support and locate physical stores. The website will be developed using HTML5, CSS3 and JavaScript, with responsive web design to support both desktop and mobile users.

The project will include a Home Page, About Us Page, Product Page, Store Locator and Customer Support Page. The website will focus on simple navigation, clear information, large product imagery and an improved overall user experience.

The website was developed using HTML5 and CSS3, with a strong focus on responsive web design. CSS techniques including Flexbox, CSS Grid, relative units and media queries were implemented to ensure that the website adapts to different screen sizes. (MDN Web Docs, 2026).

### About Us Page
The About Us Page provides information about ZARA, its history and brand.

Features include:

* ZARA company information.

* Company history.

* Mission and brand information.

* View Careers button.

* Information boxes.

* Images.

* Responsive layout.


Improvements Made
The information boxes and images were previously misaligned.

The layout was improved using Flexbox and CSS Grid to create a more organised and responsive structure.

An image that was not displaying correctly when the website was hosted on GitHub Pages was also fixed.

View Careers Button
The View Careers button on the About Us Page was fixed.

Previously, the button was not redirecting correctly.

The button was updated so that it now correctly redirects users to the intended careers destination.

When users click the button, they are redirected to the Customer Support Page, where they can find the Career Opportunities section and related information.

This provides users with a clear path from the company information section to the career-related information available on the website.

**Functionality:** Users can learn about ZARA's history, brand and global presence and access career information.

### Product Page
The Product Page allows users to view the available ZARA products and navigate between different product categories.

Features include:

* Product display.

* Product images.

* Product names and information.

* Category navigation.

* Women category.

* Men category.

* Kids category.

* New Arrivals category.

* Sale category.

* Responsive product layout.

Functionality:

Users can view the products displayed on the Product Page. When a user selects a category such as Women, the website takes the user to the relevant Women products only. The same category-based navigation is provided for the other available product sections.

The Product Page currently focuses mainly on displaying products and providing basic category navigation. More advanced shopping functionality, such as filtering, sorting, wishlist management and other e-commerce features, has not yet been implemented.

### Store Locator
The Store Locator was updated during the development process.

Original Design
The original Store Locator included a store search bar where users could enter a city or postcode.

Updated Design
The store search bar was removed.

A pressable View Place button was added instead.

The View Place button redirects users to the official store location/map view, allowing them to access physical store location information.

This change simplified the Store Locator interface and provided users with a direct way to access store location information.

### Customer Support Page
The Customer Support Page provides users with assistance, information and career-related content.

Features include:

FAQs.

Help topics.

Customer reviews.

Customer ratings.

Contact form.

Career Opportunities section.

Responsive images.

Responsive layout.

Career Opportunities
The Customer Support Page now includes a Career Opportunities section.

Users who select the View Careers on the About Us Page are redirected to this section of the Customer Support Page.

This allows users to access career-related information without adding a separate careers page to the website.

Improvements Made
The Customer Support image was previously too large and incorrectly aligned.

The image was updated using responsive CSS properties:

max-width: 100%;
height: auto;

This allows the image to resize proportionally according to the available screen width and prevents it from overflowing its container.

**Functionality:** Users can find answers to common questions, view customer feedback and send an enquiry using the contact form.

### 6. Responsive Design
Responsive design was one of the major improvements made during the second stage of development.

The website was updated to provide layouts suitable for:

* Desktop

* Tablet

* Mobile

External CSS
The external style.css file was linked to all website pages.

This allows the website to use consistent styling throughout the different pages and makes the CSS easier to maintain.

CSS Reset
A CSS reset was added to reduce default browser styling differences and create a consistent starting point for the website layout. (MDN Web Docs, 2026).

Relative Units
Fixed pixel measurements were reduced where appropriate and replaced with responsive units such as:

* rem

* %

* em

These units allow elements to scale more effectively across different screen sizes.  (web.dev, 2020)
